
КОНТРОЛЬНЫЕ ВОПРОСЫ

1. Для чего нужен JavaScript?
JavaScript нужен для добавления поведения и интерактивности веб-страниц. Например, он позволяет реагировать на нажатия кнопок и изменять содержимое страницы.

2. Как подключить внешний файл script.js?
В HTML используется тег <script src="script.js"></script>. В этой работе он расположен перед закрывающим тегом </body>.

3. Что такое DOM?
DOM (Document Object Model) — представление HTML-документа в виде объектов, с которыми может работать JavaScript.

4. Для чего нужен querySelector()?
Метод document.querySelector() находит первый HTML-элемент, соответствующий указанному CSS-селектору. Например, querySelector("#buy") находит элемент с id="buy".

5. Что такое событие click?
click — событие, которое возникает при нажатии пользователя на элемент, например кнопку.

6. Что делает addEventListener()?
Метод addEventListener() назначает элементу обработчик события. Когда событие происходит, выполняются команды обработчика.

7. Зачем используется textContent?
Свойство textContent позволяет прочитать или изменить обычный текст внутри HTML-элемента.

8. Почему сообщение появляется только после нажатия?
Потому что обработчик выполняется только после события click. До нажатия текст соответствующего абзаца остаётся пустым.

9. Чем отличаются селекторы #buy и .product?
#buy выбирает элемент с идентификатором buy. .product выбирает элемент или элементы с классом product. Символ # используется для id, точка — для class.

10. Что произойдёт, если указать несуществующий id?
document.querySelector() вернёт null, так как элемент не найден. Если затем вызвать у null метод addEventListener() или обратиться к его свойству, возникнет ошибка.

САМОСТОЯТЕЛЬНАЯ РАБОТА — ВЫПОЛНЕНО

1. Изменено сообщение после нажатия «Купить»: «Отлично! Товар добавлен в корзину.»
2. Изменён текст после нажатия «Подробнее»: добавлены сведения о гарантии, Bluetooth и комплектации.
3. Добавлена кнопка «Доставка» и пустой абзац с id="delivery-info".
4. Добавлен обработчик доставки. После нажатия появляется: «Доставка по городу — 300 ₽».
5. Добавлена кнопка «Очистить». Она удаляет сообщение о покупке, присваивая его textContent пустую строку.
